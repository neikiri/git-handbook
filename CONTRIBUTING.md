# Contributing

Pull requests are welcome.

This repository is a practical Git and GitHub handbook. If you find something unclear, incorrect, or missing, feel free to open an issue or submit a pull request.

## How to contribute

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Submit a pull request.

## Guidelines

- Keep changes focused.
- Use clear commit messages.
- Make sure examples and commands are accurate.
- Be respectful and constructive.
